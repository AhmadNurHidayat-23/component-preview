# Component Preview

Pratinjau komponen antarmuka dari katalog React tepercaya dengan properties yang dapat diubah.

## Fitur

- Button, input, modal native dialog, card, dan form yang interaktif.
- Ukuran kecil/sedang/besar, varian solid/outline/quiet, label, deskripsi, disabled, required, dan tipe input.
- Preview adaptif/mobile/tablet, tema terang/gelap terpisah untuk preview.
- Salin/download implementasi React, CSS, dan contoh penggunaan.
- Tidak mengeksekusi JavaScript dari input pengguna.

## Teknologi

React 19, TypeScript, Vite, Vitest.

## Cara menjalankan

Memerlukan Node.js 22.12+.

```sh
npm ci
npm run dev
```

Buka alamat yang dicetak terminal. Jalankan `npm test` untuk pengujian dan `npm run build` untuk build produksi.
